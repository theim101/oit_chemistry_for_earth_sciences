// Examples of simple Freundlich and Langmuir models.
// This file can be used as database file in the orchestra chemistry file, which makes these models available for selection in the GUI.
// The models can than be connected to chosen particle (phases) 
// The modes can be extended with adsorption reactions for more ions.

//**** Model type code **** 
@class: adsorptionmodelcode(Basic_surface){
   @class: Basic_surface(name, parent_phase ,concentration){
      // The Basic surface model just contains of a single phase
      // that is linked to its parent phase via its concentration
      @phase(<name>, <parent_phase>, <concentration>)
   }
}


@class: adsorptionmodeltext(Langmuir){
A simple example of a 1 site Langmuir model implementation.

}

@adsmodel(Langmuir, part , 1, Basic_surface)
@surfsite(Langmuir, S, 1, 1)
@surfspecies(Langmuir, S, S-Na, 1)
@logKreaction(Langmuir_S-Na, 1.7, 1.0, Langmuir_S, 1.0, Na+)
@surfspecies(Langmuir, S, S-NH4, 1)
@logKreaction(Langmuir_S-NH4, 2.3, 1.0, Langmuir_S, 1.0, NH4+)


@class: adsorptionmodeltext(Freundlich){
A simple example of a Freundlich model implementation

q = k*c^(1/n)
or 
amount sorbed = k * dissolved concentration^(1/n)


For a Freundlich model, the log activity of the adsorption site is constant 0.

Note the different stoichimetry coefficients for mass action and mass balance in the reaction equations.

For the interaction with the surface site this needs to be "1, 0" mass action = 1, mass balance = 0 (no contribution to site mass balance) (activity of site = constant 1)
For the coefficients for the adsorbing ion the mass balance coefficient is 1, and the mass action = 1/n, so for Na "0.7, 1.0"

}

@adsmodel(Freundlich, part ,1 , Basic_surface)
@surfsite(Freundlich, S, 1, 1)
@surfspecies(Freundlich, S, S-Na, 1)
@logKreaction(Freundlich_S-Na, 1.7, "1, 0", Freundlich_S, "0.7, 1.0" Na+)
@surfspecies(Freundlich, S, S-NH4, 1)
@logKreaction(Freundlich_S-NH4, 2.3, "1, 0", Freundlich_S, "0.7, 1.0", NH4+)
