
@class: adsorptionmodeltext(dummy){
//----------------------------------------------------------------------------------------
// For the Uranium system we define an exchange plane with 1 "site" 
// Local concentrations are in equivalent fractions.
// Note that the empty site has a mass balance factor of 0, so it does not contribute to the
// total sum of equivalent fractions, so fraction of empty sites == 0
// This results in all sites being occupied with either Na or U
// The log K of the Na species is 0.
// Also note that the GT_X2-U species has different mass-action and mass balance coefficients
// to translate the equivalent fractions to moles (1 equivalent of this species agrees with 0.5 Mol U)
//----------------------------------------------------------------------------------------
}
//**** End of model specific text ****
